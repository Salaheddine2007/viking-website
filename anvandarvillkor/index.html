Användarvillkor

Genom att beställa ett abonnemang hos Viking IPTV godkänner du villkoren nedan.

Abonnemang

Viking IPTV säljer tidsbegränsade abonnemang (1, 3, 6 eller 12 månader). Detaljer om pris och innehåll för varje paket finns på prissidan. Beställning och betalning hanteras via WhatsApp-konversationen med vårt supportteam.

Kanalutbud kan förändras

Precis som hos andra streamingtjänster kan enskilda kanaler, program eller VOD-titlar tillkomma eller försvinna under abonnemangsperioden. Vi lovar därför inte ett statiskt eller garanterat utbud, men strävar efter att hålla ett brett och stabilt kanalutbud över tid.

Ditt ansvar som användare

Det är ditt ansvar att kontrollera att din användning av tjänsten följer gällande lagstiftning i det land du befinner dig i. Läs gärna vår guide om vad svensk lag säger om IPTV om du är osäker.

Support och reklamation

Vid tekniska problem eller frågor om ditt abonnemang, kontakta supporten via WhatsApp så hjälper vi dig så snabbt vi kan.

Ändringar av villkoren

Vi kan uppdatera dessa villkor från tid till annan. Den senaste versionen gäller alltid och publiceras på denna sida.
